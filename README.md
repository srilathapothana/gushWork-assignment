## ✅ Features Implemented

### 1. Sticky Header
- Appears with a smooth transition when the user scrolls past the product section
- Automatically hides when scrolling back to the top
- Uses scroll direction detection for clean show/hide behaviour

### 2. Image Carousel with Zoom
- Click thumbnails or left/right arrows to navigate between product images
- Hover over the main image to trigger a **zoom preview box**
- Zoom preview uses `position: fixed` with viewport-aware coordinates — works correctly at any scroll depth
- Preview auto-flips to the left side if there isn't enough space on the right

### 3. Responsive Design
- Fully responsive across **desktop**, **tablet**, and **mobile**
- Breakpoints at 1600px, 1200px, 800px, 768px, 480px, and 460px
- Mobile hamburger menu for navigation
- Product layout stacks vertically on small screens

### 4. Additional Functionality
- FAQ accordion (open/close on click)
- Manufacturing process tabs (desktop) and swipe carousel (mobile)
- Applications carousel with touch swipe support
- Testimonials drag-to-scroll carousel
- Contact form with validation
- Catalogue email form
- Scroll reveal animations using IntersectionObserver
- Responsive company logos (shows/hides based on viewport width)
